AGENT CONTROL

Plan with AI. Write with code.

CLI and stdio MCP share this app's journal. Agents can create draft batches, inspect, pause, export and report. They cannot arm a run or write raw pages.

python nfcctl.py status
python nfcctl.py inspect
python nfcctl.py mcp

The default commands connect to the demo workspace. Use --mode hardware for a physical workspace.

Phone station · planned, not implemented

Android Chrome Web NFC is a possible low-cost NDEF station, but cannot inspect security pages or prove NTAG215 geometry. A native Android NfcA bridge is the full-inspection option. Neither phone adapter ships in this release.
